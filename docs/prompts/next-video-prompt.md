# Reusable prompt for the next video

This is a new reusable prompt derived from the approved standard. The original prompt is saved separately in `original-video-prompt.md`.

Providing a local video path as input in this repository's agent chat now starts the workflow through `AGENTS.md`; this longer prompt is optional when you want to specify audience, targets, or deliverables. A path alone requests an edited Studio preview. Add “export MP4” when you want a rendered file.

---

Create the next Posiblo video in this project using `docs/video-standard.md` and the approved reference at `references/posiblo-v1/out/not-every-business-needs-ai-posiblo.mp4`.

Input footage: <absolute path>
Audience: <audience>
Main message: <message>
Desired viewer action: <action or closing question>
Output slug: <unique slug>
Deliverable: <Studio preview / finished MP4>
Target platforms and placements: <Facebook Reels / Instagram Reels / TikTok / other>
Distribution: <organic / paid; specify per placement>

Read AGENTS.md and the relevant installed Remotion skills. Preserve the approved baseline and original footage. Create a distinct composition and complete the video brief and review record using the project templates.

Follow `docs/social-media-video-workflow.md`, including local-path intake and project-context discovery, and apply `docs/social-media-video-best-practices.md` to the intended platforms and placements. Read the video standard, brief template, and review template; inventory docs and inspect relevant supporting code, scripts, assets, and configuration. Record applied context and avoid carrying recording-specific script edits into new footage. If targets are unspecified, record the workflow's provisional organic three-platform plan. In the brief, map each target placement to relevant guidance, concrete implementation, and current official specification evidence or unknowns. Verify changing requirements before final delivery; do not rerun the full research prompt unless a research refresh is needed.

Keep the real speaker and voice, Posiblo's dark and lime visual identity, readable Hebrew RTL captions with active-word highlighting, purposeful animated explanations and workflow diagrams, and smooth transitions. Adapt the scenes and pacing to the actual speech. Do not invent dialogue, uncertain subtitles, or claims of human review. Use free local tooling; do not use paid services without authorization.

Match or exceed the reference across all review dimensions. Choose and document at least one concrete improvement and verify it. Inspect representative scenes, transitions, and phone-size readability. If a finished MP4 is requested, render to a unique path, verify that exact file, and review the full export with sound. Report the output path, improvements, automated results, and any pending human Hebrew caption review or other limitation.

Record a separate compatibility verdict for each target placement, with actual preview evidence where available. Keep unverified specifications, platform overlays, rights/disclosures, and human checks pending. Link the completed brief and review in the handoff. Define a relevant metric or test hypothesis without inventing campaign results. Do not publish or buy distribution without authorization.
